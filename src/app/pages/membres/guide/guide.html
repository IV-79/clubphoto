Guide des membres

Comment participer aux deux grandes activités du club : le OneShot et le Thème du mois.

OneShot

Un événement photo libre, lancé par n'importe quel membre, avec vote final.

Le principe

Un OneShot est un événement thématique créé par un membre. Il définit un ou plusieurs thèmes, les participants s'inscrivent et soumettent leurs photos. Quand l'organisateur clôture les inscriptions, le vote s'ouvre et les membres élisent leurs photos préférées. À la fin, le classement est révélé avec les noms.

Contrairement au Thème du mois, un OneShot est entièrement géré par son créateur — c'est lui qui avance manuellement les étapes.

Les 4 étapes d'un OneShot

Préparation
Invisible aux autres membres. L'organisateur configure l'événement : titre, description, date, thèmes photo.
Inscriptions ouvertes
Les membres peuvent s'inscrire. L'organisateur uploade les photos et peut encore ajouter ou renommer des thèmes. Les thèmes restent une information interne — les participants ne les voient pas encore.
Inscriptions fermées (optionnel)
Les inscriptions sont closes mais le vote n'a pas encore démarré. L'organisateur peut encore ajuster les thèmes et finaliser les photos. Utile pour tout vérifier avant d'ouvrir le vote.
Vote
Les thèmes et les photos sont révélés aux participants. Plus d'inscriptions, d'uploads ni de modification des thèmes. Chaque participant vote pour une photo par thème (pas la sienne). Les noms sont masqués.
Résultats
Le classement est publié. Les noms sont révélés, les égalités partagent le même rang (ex : deux 2ᵉ places).

Créer un OneShot

  1. Allez dans Mon espace → Mes OneShots via le menu en haut à droite.
  2. Cliquez sur + Créer un événement.
  3. Renseignez le titre (obligatoire), une description et une date optionnelles.
  4. L'événement démarre en mode Préparation — personne ne le voit encore.
  5. Depuis la page de gestion, ajoutez vos thèmes (ex : "Paysage", "Portrait").
  6. Quand tout est prêt, cliquez Ouvrir les inscriptions pour le rendre visible.

Participer à un OneShot

  1. Rendez-vous sur Galeries → OneShot.
  2. Ouvrez un événement dont le statut est Inscriptions ouvertes.
  3. Inscrivez-vous — l'organisateur pourra ensuite uploader vos photos.
  4. Pendant la phase Vote, parcourez les photos et votez pour celles que vous préférez (sauf les vôtres).
  5. Les Résultats sont visibles dès que l'organisateur clôture le vote.

Les photos sont uploadées par l'organisateur, pas par les participants eux-mêmes.

Gérer son OneShot (organisateur)

  1. Depuis Mon espace → Mes OneShots, cliquez Gérer sur votre événement.
  2. Ajoutez et renommez les thèmes tant que vous êtes en Préparation, Inscriptions ou Inscriptions fermées. Dès le passage en Vote, les thèmes sont verrouillés et révélés aux participants.
  3. Pour ajouter des photos : section Photos → Gérer les photos. Glissez plusieurs fichiers en une fois. Assignez chaque photo à un membre et un thème.
  4. Avancez les étapes dans l'ordre avec le bouton Avancer (action irréversible, une confirmation est demandée).
  5. Le bouton Fermer les inscriptions d'abord est optionnel : il vous permet de bloquer les nouvelles inscriptions et uploads le temps de tout vérifier, avant d'ouvrir le vote.

Thème du mois

Une compétition mensuelle organisée par le club, avec soumission directe par les membres.

Le principe

Chaque mois, l'équipe du club propose un thème photo. Les membres soumettent leurs photos directement depuis la galerie. Les phases changent automatiquement selon les dates définies par l'admin — aucun bouton à actionner pour avancer les étapes.

Créer un thème (administrateurs)

Depuis Admin → Thèmes, cliquez Nouveau thème. Le formulaire comprend :

Titre Le sujet du mois, ex : « Lumière naturelle ».
Description Optionnel — consignes, inspiration, règles particulières.
Mois Sélecteur mois/année. Remplit automatiquement les 3 dates dès la sélection (voir ci-dessous) — ajustez ensuite si besoin.
Ouverture soumissions Auto : 1ᵉʳ du mois sélectionné. À partir de cette date, les membres peuvent soumettre une photo.
Clôture soumissions Auto : dernier jour du mois sélectionné. Plus de soumissions après cette date ; le vote s'ouvre.
Fin du vote Auto : 15 du mois suivant. Après cette date, les résultats sont publiés automatiquement.
Photos / membre Défaut : 1. Nombre max de soumissions par participant.
Votes / membre Défaut : 3. Nombre de votes qu'un membre peut répartir sur les photos.

Il n'y a pas de bouton « passer à l'étape suivante » — le statut est calculé en temps réel à partir des dates. Pour corriger une erreur, supprimez le thème et recréez-le (possible tant qu'aucune soumission n'existe).

Les 4 phases

En attente
Le thème est annoncé mais les soumissions ne sont pas encore ouvertes. Préparez vos photos !
Ouvert
Soumission ouverte. Uploadez votre photo directement sur la page du thème. Vous pouvez supprimer et re-soumettre tant que la clôture n'est pas atteinte.
Vote
Les photos sont là, les noms sont masqués. Votez pour vos préférées (pas la vôtre). Vous avez un nombre limité de votes. Vous pouvez retirer un vote et le redéposer ailleurs.
Résultats
Classement final avec noms, votes et médailles. Les égalités partagent le même rang.

Soumettre une photo

  1. Allez sur Galeries → Thèmes du mois.
  2. Ouvrez le thème dont le statut est Ouvert.
  3. Glissez votre photo dans la zone d'upload ou cliquez dessus pour choisir un fichier.
  4. La photo est compressée automatiquement (max 5 Mo, JPEG/PNG).
  5. Pour supprimer votre soumission, cliquez le ✕ sur votre photo (marquée "Ma photo").

Vous ne pouvez soumettre qu'une photo par thème (sauf indication contraire de l'admin).

Voter

  1. Pendant la phase Vote, ouvrez le thème.
  2. Cliquez sur une photo pour voter pour elle. Les photos sont anonymes.
  3. La barre de progression en haut indique vos votes restants.
  4. Cliquez à nouveau sur une photo votée pour retirer votre vote et le déposer ailleurs.
  5. Vous ne pouvez pas voter pour votre propre photo.

Visionner les photos

Dans toutes les phases, cliquez sur le bouton ⤢ en haut à droite d'une photo pour l'ouvrir en plein écran. Naviguez avec les flèches à l'écran ou les touches ← → du clavier.
